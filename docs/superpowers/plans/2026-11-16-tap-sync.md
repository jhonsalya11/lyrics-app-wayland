# Sinkronisasi Lirik dengan Klik (Tap-Sync) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pengguna menandai tiap baris lirik biasa dengan mengklik baris itu (atau menekan Spasi) saat dinyanyikan; aplikasi menyimpan hasilnya sebagai `.lrc` bertimestamp.

**Architecture:** Logika murni (`SyncSession`, `format_timestamp`) di modul baru `syncer.py`. `ui.py` mendapat mode sinkron (baris yang bisa diklik, bilah progres, Simpan/Batal, fokus keyboard sementara). `app.py` merangkai: posisi lagu dari `PositionEstimator` dikurangi `sync_offset`, validasi urutan, simpan lewat `save_custom`.

**Tech Stack:** Python 3.12, PyGObject (Gtk 3.0), `unittest`. Tanpa dependensi baru.

**Spec:** `docs/superpowers/specs/2026-11-16-tap-sync-design.md`

## Global Constraints

- Tidak ada tombol geser ±0,1 detik, tidak ada undo bertingkat, tidak ada seek ke Firefox. Koreksi hanya dengan klik ulang.
- Mode sinkron hanya ditawarkan untuk lirik **biasa** (`Lyrics.synced == False`). Baris kosong dilewati.
- Timestamp = posisi lagu dari `PositionEstimator` dikurangi `sync_offset`, tidak kurang dari 0; format `[mm:ss.xx]` (2 digit pecahan).
- `sync_offset` ada di `~/.config/lyrics-pip/config.json`, bawaan `0.3`, nilai tidak valid jatuh ke `0.3`, dibatasi `[0.0, 2.0]`.
- Jendela utama tidak menerima fokus keyboard, **kecuali selama mode sinkron**; setelah keluar mode kembali `set_accept_focus(False)`. Tombol di jendela tetap `set_can_focus(False)` agar Spasi tidak mengaktifkan tombol.
- Hasil disimpan lewat `save_custom(...)` ke `lyrics/` (di-ignore git, tidak pernah di-commit).
- Teks UI Bahasa Indonesia. Tes `unittest` (`python3 -m unittest discover -s tests`). Commit per tugas; **jangan push** (tanyakan pengguna di akhir).

## Review Focus

- Lagu berganti saat mode sinkron aktif: mode dibatalkan, tanda dibuang, tidak crash. (Task 3)
- Tanda yang tidak berurutan (klik ulang baris awal terlalu belakangan): penyimpanan ditolak dan baris bermasalah ditandai; lirik tidak pernah tersimpan dengan urutan teracak. (Task 1 dan 3)
- Klik atau Spasi saat tidak ada lagu (Firefox hilang/ditutup): tidak ada tanda yang dibuat, tidak crash. (Task 3)
- Pembulatan: 59,999 detik menjadi `[01:00.00]`, bukan `[00:60.00]`; lirik hanya berisi baris kosong tidak masuk mode sinkron. (Task 1 dan 3)
- Fokus: setelah keluar mode sinkron (Simpan, Batal, atau lagu berganti) jendela kembali tidak menerima fokus; Spasi di mode sinkron menandai baris, bukan menekan tombol. (Task 2)

### Task 2: Mode sinkron di jendela (UI)

**Files:**
- Modify: `lyrics_pip/ui.py`

**Interfaces:**
- Consumes: tidak ada dari tugas lain (tidak memakai `SyncSession`; menerima daftar teks).
- Produces di `LyricsWindow`:
  - `on_sync: Callable[[], None] | None` (dipanggil saat tombol ⏱ diklik) dan `set_sync_button_visible(visible: bool) -> None` (tombol ⏱ di header, tooltip "Sinkronkan lirik", awalnya tersembunyi).
  - `in_sync_mode: bool` (atribut, awalnya `False`).
  - `enter_sync_mode(texts: list[str], on_mark: Callable[[int], None], on_mark_next: Callable[[], None], on_save: Callable[[], None], on_cancel: Callable[[], None]) -> None`: mengganti area lirik dengan satu baris yang bisa diklik per teks (klik -> `on_mark(index)`; peristiwa klik tidak boleh memulai geseran jendela), menampilkan bilah dengan label progres dan tombol **Simpan** dan **Batal**, menyembunyikan tombol ⟳, ✎, ⏱, mengaktifkan `set_accept_focus(True)`, dan menyambungkan tombol **Spasi** (peristiwa `key-press-event` jendela) ke `on_mark_next`.
  - `set_sync_row(index: int, stamp_text: str | None) -> None`: tampilkan stempel kecil abu-abu di depan baris (`None` menghapusnya).
  - `set_sync_state(next_index: int | None, done: int, total: int, message: str = "", bad_index: int | None = None) -> None`: sorot baris `next_index`, tampilkan `Sinkron: {done}/{total} baris` ditambah `message` bila ada, beri gaya galat pada `bad_index`, dan aktifkan tombol Simpan hanya bila `done == total`.
  - `exit_sync_mode() -> None`: keluar mode, `set_accept_focus(False)`, `in_sync_mode = False`, mengembalikan tombol header sesuai keadaan sebelum masuk; area lirik dikosongkan (pemanggil menampilkan ulang lirik/pesan sendiri).

- [ ] **Step 2: Verifikasi di Xvfb** (`xvfb-run -a python3 skrip_sementara.py`, bukan di layar pengguna). Expected (dicetak skrip): (a) `in_sync_mode` `False` -> `True` -> `False`; (b) mengklik baris ke-2 memanggil `on_mark(1)`; (c) menyinyalkan `key-press-event` Spasi memanggil `on_mark_next()` dan tidak mengaktifkan tombol Simpan/Batal; (d) `set_sync_row(0, "[00:01.00]")` menambah stempel dan `set_sync_row(0, None)` menghapusnya; (e) `set_sync_state(1, 1, 2)` -> tombol Simpan nonaktif, `set_sync_state(None, 2, 2)` -> aktif; (f) tombol Simpan dan Batal memanggil `on_save` / `on_cancel`; (g) `exit_sync_mode()` mengembalikan `get_accept_focus()` ke `False` dan tombol ⟳/✎ kembali sesuai keadaan sebelumnya; (h) tombol ⏱ tersembunyi awalnya, terlihat setelah `set_sync_button_visible(True)`, dan mengkliknya memanggil `on_sync`. Hapus skrip sementara.
